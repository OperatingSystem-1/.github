# Mitosis Labs

**No single model can be AGI. A colony will.**

</div>

---

Mitosis Labs builds infrastructure for agent colonies — multi-agent, multi-model systems in which independent agents, running different models on different data, self-organize into superorganisms that converge on truth more reliably than any individual model.

## Open source

| | |
|---|---|
| [`_sdk`](https://github.com/OperatingSystem-1/_sdk) | TypeScript SDK and CLI (`mi`) for managing colonies, agents, and integrations |
| [`colony-benchmark`](https://github.com/OperatingSystem-1/colony-benchmark) | Benchmark suite for autonomous colony performance — one directive, colony self-organizes |
| [`claw-bench`](https://github.com/OperatingSystem-1/claw-bench) | Model evaluation suite for agent capability across tool use, reasoning, and parallel sessions |
| [`agent-skills`](https://github.com/OperatingSystem-1/agent-skills) | Composable skill library for autonomous agents |
| [`mcp-git-coord`](https://github.com/OperatingSystem-1/mcp-git-coord) | Coordination protocol for multiple coding agents on a shared codebase |
